## 변경 사항

- **msPb MUC/MUB 음량 일치**: 템포 설정만 하는 OPNA 파트를 믹서의 발음 칩으로 세지 않도록 수정했습니다. 같은 PSG·SCC·SCC+ 연주에서 불필요한 자동 음량 보정 차이를 줄입니다. 실제 OPNA 연주와 SCC-SSG의 노이즈·엔벌로프 경로는 유지합니다.
- 루프가 명령 인자로 진입하는 경우와 미완성 페이지의 칩 판정을 보완했습니다. 템포·쉼표만 있는 무음 파일도 정상적으로 로드하고 종료합니다.
- OPNA의 선택되지 않은 리듬 파트가 다른 파트의 직접 레지스터 드럼 연주를 끊는 문제를 수정했습니다.
- 여러 드럼을 선택한 `pm1 p4..p6` 자동 팬 명령에서 드럼별 대기 시간이 빠지는 컴파일 문제를 수정했습니다.
- 최신 MUCOMSX에 맞춘 기본 템포, SCC 공통 파형 포트와 캐시, raw 명령 경계 판독, MUC의 UTF-8 BOM·CP/M EOF 처리를 반영했습니다.

## 다운로드

Apple Silicon용 **MDPlayer4Mac-osx-arm64.zip**을 내려받아 압축을 풀고 `MDPlayer4Mac.app`을 실행하세요.
macOS 13 이상에서 사용할 수 있으며 .NET 런타임이 포함되어 있습니다.

## 검증

- 합성 MUB 20개와 MUC 20개를 정상 종료까지 재생했습니다.
- 회귀 검사 **1,284,281개 통과**. 타이머 샘플 단위 검사 등을 포함한 수치이며 곡 수가 아닙니다.
- 칩 판정·루프 진입·재로드 집중 검사 **634개 통과**.
- PSG·SCC·SCC+ fixture의 MUC/MUB PCM 및 타이밍 일치와 두 루프 경계를 확인했습니다.
- 믹서 안정성 보완 전후 MUB fixture 20개의 PCM과 재생 시간이 동일합니다.

앱은 기존 릴리즈와 같은 ad-hoc 서명을 사용하며, Apple Developer ID 서명 및 notarization은 적용되지 않았습니다.
최초 실행 안내와 지원 형식은 [사용 안내](https://github.com/ToughkidDev/MDPlayer4Mac/blob/v0.2.2/macos/README.md)를 참고하세요.
