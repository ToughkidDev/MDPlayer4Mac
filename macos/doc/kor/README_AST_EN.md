# FileAssociationTool
주로 음악 데이터 파일의 아이콘과 실행 애플리케이션을 설정하기 위한 도구
  

[요약]  
  이 도구는 주로 음악 데이터 파일의 아이콘과 실행 애플리케이션을 설정하는 데 사용합니다.  
  준비한 ico 파일의 파일명을 보고 해당 파일 확장자에 대한 설정을 레지스트리에 기록합니다.  
  

[주의]  
  이 도구는 Explorer 등의 관련 레지스트리를 삭제 및 갱신하여 파일의 아이콘과 실행 애플리케이션을 지정합니다.  
  이 도구를 실행하기 전에 컴퓨터를 백업해 주세요.  
  사용자는 자신의 행동에 책임을 지며, 이로 인해 발생할 수 있는 어떠한 문제에 대해서도 저희는 책임지지 않음을 유의해 주세요.  
  

[간단한 사용법]   
  1. 먼저 .ico 파일을 준비합니다. 파일명은 다음과 같이 지정합니다.  
  　　mdp_???.ico  
     ???는 설정할 파일의 확장자입니다.  
     예를 들어 .vgm과 .xgm을 설정하려면 각각 mdp_vgm.ico와 mdp_xgm.ico를 준비합니다.  

  2. FileAssociationTool.exe가 있는 폴더에 "ico" 폴더를 만들고, 준비한 .ico 파일을 그 안에 복사합니다.  

  3. FileAssociationTool.exe를 실행합니다. 1단계와 2단계를 따랐다면 설정이 그에 맞게 조정됩니다.  
  그렇지 않다면 기본값이 표시되므로 직접 조정할 수 있습니다.  

  4. "실행할 프로그램의 전체 경로(와 옵션)",  
  파일을 더블클릭했을 때 실행하고 싶은 프로그램이 "실행할 프로그램의 전체 경로(와 옵션)"에 올바르게 지정되어 있는지 확인합니다.  
  기본값은 "C:\MDPlayer\MDPlayerx64.exe" "%1" 입니다.  
  (MDPlayer를 기본값으로(특별히 변경하지 않고) 설치했다면 이 기본값으로 충분합니다.)  

  5. "실행" 버튼을 클릭하면 설정이 적용되고, 성공하면 "Success" 대화상자가 표시됩니다.  

  6. "X" 버튼을 클릭하여 종료합니다.  
  


[설정 항목 설명]  
  [확장자]  
      설정할 확장자를 나열합니다. ";"를 구분 문자로 사용합니다.  
      예를 들어 .vgm과 .xgm을 설정하려면 ".vgm;.xgm"을 입력합니다.  
  
  [새 레지스트리 키 접두사]  
      확장자별 상세 설정을 저장하기 위해 추가/덮어쓸 레지스트리의 이름을 설정합니다.  
      특별한 사정이 없다면 기본값인 "MDPlayer"를 그대로 두어도 됩니다.  
      예를 들어 .vgm과 .xgm을 설정하려면 "MDPlayer.vgm"과 "MDPlayer.xgm"이라는 레지스트리 이름이 추가됩니다.  
  
  [.ico 파일이 있는 전체 경로]  
      설정할 .ico 파일의 전체 경로를 지정합니다.  
      지정한 전체 경로에 "???"가 포함되어 있으면 그 부분은 "확장자" 항목에서 지정한 확장자명으로 바뀝니다.  
      예를 들어 "c:\ico\mdp_???.ico"를 지정하고 "확장자"에 ".vgm;.xgm"을 지정하면,  
      "c:\ico\mdp_vgm.ico"와 "c:\ico\mdp_xgm.ico"  
      가 지정됩니다.  
  
  [실행할 프로그램의 전체 경로(와 옵션)]  
      기본값으로 "C:\MDPlayer/MDPlayerx64.exe" "%1"이 입력되어 있습니다.  
      MDPlayer를 기본값으로(특별히 변경하지 않고) 설치했다면 이 기본값으로 충분합니다.  
      그렇지 않다면 값을 조정해 주세요.  
      참고로 "%1"은 더블클릭한 파일의 전체 경로를 의미합니다.
