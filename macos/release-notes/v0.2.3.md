## 변경 사항

- **msPb0102 SCC/SCC+ 음표 재생**: 전용 5채널 `SCCA`–`SCCE` 악보, 인라인 32샘플 파형과 SCWD 뱅크를 지원합니다. 다섯 번째 독립 파형과 SCC 선형 음량을 처리합니다.
- SCC 채널을 OPNA FM·리듬·ADPCM 및 MSX PSG와 분리했습니다. 기존 `msPb0100`/`0101`과 일반 MUCOM 재생 경로는 유지합니다.
- 반복문 직후 같은 음 타이를 합치면서 반복 점프 주소를 덮어쓰던 MUC 컴파일러 오류를 수정했습니다. 곡 중간의 재생 중단·예외를 방지합니다.
- 사용하지 않는 마지막 페이지를 제거해 빈 페이지 때문에 음악 용량 초과로 거절되던 파일을 처리합니다. 실제 작성한 페이지 번호와 음악 용량 한도는 유지합니다.
- 잘못된 SCC 프로필·파형·뱅크를 검사하고, 컴파일 모드가 일반 MUC에 남지 않도록 격리했습니다.

## 검증

- MSX 재생 회귀 검사 **1,284,854 assertions 통과**. 검사 횟수이며 곡 수가 아닙니다.
- 독립 SCC 5채널, OPNA FM 양쪽 뱅크와 PSG의 동시 연주, 정상 종료, 루프, 페이지 9, 파형 뱅크 CRC와 잘못된 입력을 검사했습니다.
- 반복문 뒤 타이를 명시적으로 펼친 악보와 비교해 출력 PCM과 종료 시점이 같은지 확인했습니다.
- 별도 SCC 앨범 검증에서 변환본 **422쌍의 MUC/MUB 출력 PCM 일치**를 확인했습니다. 원본 VGM의 전체 파형 동일성이나 전곡 실기 검증을 뜻하지 않습니다.

## 다운로드

Apple Silicon용 **MDPlayer4Mac-osx-arm64.zip**과 **.zip.sha256**을 제공합니다.
압축을 풀고 `MDPlayer4Mac.app`을 실행하세요. macOS 13 이상, .NET 런타임 포함입니다.

기존 릴리즈와 같은 ad-hoc 서명을 사용하며 Developer ID/notarization은 적용되지 않았습니다.
[사용 안내](https://github.com/ToughkidDev/MDPlayer4Mac/blob/v0.2.3/macos/README.md)를 참고하세요.
