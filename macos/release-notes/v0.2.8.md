`msPb0100~0102` 곡을 컴파일할 때 원래 헤더 태그를 보존하도록 수정했습니다.
[PR #3](https://github.com/ToughkidDev/MDPlayer4Mac/pull/3)의 변경을 포함합니다.

## 변경 사항

- MSX 프로필 MUB의 태그를 복사할 때 원래 MUB 헤더의 태그 위치와 크기를 사용합니다.
- 제목 등 메타데이터와 OPNA 드라이버 설정이 컴파일 결과에서 누락되던 문제를 수정했습니다.
- 일반 SCC 행과 인라인 `@W` 음색을 사용하는 `msPb0102` 곡에서도 `#CarrierCorrection`을 보존합니다.
- 기존 OPNA 문법과 MSX 확장 명령을 유지합니다. macOS 전용 네이티브 코어의 수정이며 MSX COM 툴체인과는 별개입니다.

## 검증

- `msPb0102` 출력 형식·제목 태그 보존과 실제 OPNA 캐리어 음량 차이를 검사하는 회귀 검사를 추가했습니다.
- 릴리즈 전 독립 코어 및 오디오 엔진 회귀 검사와 UI 빌드를 수행하고, GitHub 배포 작업에서도 재검사합니다.
- 배포 작업에서 앱 서명·ZIP 검증과 패키지 시작 검사를 수행합니다.
- 자동 검사이며 전곡 청음이나 원본 게임 전체와의 파형 동일성 검증을 뜻하지 않습니다.

## 알려진 제한

이전 버전의 장시간 곡 루프 감지, 일부 들여쓴 비연주 행 전처리와 압축 행 `/` 반복 탈출 제한은 그대로입니다.
