# FileAssociationTool
주로 음악 데이터 파일의 아이콘과 실행 앱을 설정하기 위한 도구
  

[개요]  
  주로 음악 데이터 파일의 아이콘과 실행 앱을 설정하기 위한 도구입니다.  
  준비한 ico 파일의 파일명을 보고 대응하는 확장자에 대한 설정을 레지스트리에 기록합니다.  
  

[주의]  
  ・이 도구를 사용하면 Explorer 등의 관련 레지스트리를 삭제, 갱신하여 파일의 아이콘과 실행 앱을 지정합니다.  
  예상치 못한 동작 결과가 나올 수도 있으므로 실행 전에 백업 등의 대책을 마련해 주세요.  
  실행은 '자기 책임'이며, 이로 인해 무슨 일이 일어나더라도 저희는 일절 책임지지 않습니다.  
  

[간단한 사용 방법]  
  1.먼저 .ico 파일을 준비합니다. 파일명은 다음과 같이 합니다.  
  　　mdp_???.ico  
  ???에는 설정 대상이 되는 파일의 확장자가 들어갑니다.  
  예를 들어 .vgm과 .xgm을 설정하고 싶다면 각각 mdp_vgm.ico, mdp_xgm.ico를 준비합니다.  

  2.FileAssociationTool.exe가 있는 폴더에 'ico' 폴더를 만들고 그 안에 준비한 .ico 파일을 복사해 둡니다.  

  3.FileAssociationTool.exe를 실행합니다. 1과 2의 절차를 거쳤다면 설정값이 그에 맞게 조정됩니다.  
  그렇지 않으면 초기값이 표시되므로 직접 조정해 주세요.  

  4.'실행할 프로그램의 전체 경로(와 옵션)'에,  
  파일을 더블클릭했을 때 등에 실행하고 싶은 프로그램이 올바르게 지정되어 있는지 확인합니다.  
  초기값은 「"C:\MDPlayer\MDPlayerx64.exe" "%1"」이 입력되어 있습니다.  
  (MDPlayer를 기본값(특별히 변경하지 않고)으로 설치한 경우에는 이 초기값으로 문제없을 것입니다.)  

  5.'실행' 버튼을 누르면 설정이 실시되고, 성공하면 'Success' 대화상자가 표시됩니다.  

  6.'×' 버튼을 눌러 종료합니다.  
  

[설정 항목 설명]  
  '확장자'  
      설정하고 싶은 확장자를 나열합니다. ';'를 구분 문자로 사용합니다.  
      예를 들어 .vgm과 .xgm을 설정하고 싶다면 「.vgm;.xgm」이라고 입력합니다.  
  '새 레지스트리 키의 접두사'  
      확장자별 상세 설정을 저장하기 위해 추가/덮어쓰기할 레지스트리의 이름을 설정합니다.  
      특별한 사정이 없다면 초기값인 'MDPlayer' 그대로 두어도 문제없습니다.  
      예를 들어 .vgm과 .xgm을 설정하고 싶다면 'MDPlayer.vgm', 'MDPlayer.xgm'이라는 레지스트리가 추가됩니다.  
  '.ico 파일이 있는 전체 경로'  
      설정하고 싶은 .ico 파일을 전체 경로로 지정합니다.  
      이때 지정한 전체 경로에 '???'가 있으면 그 부분을 '확장자'에서 지정한 확장자명으로 바꿔서 설정합니다.  
      예를 들어 「c:\ico\mdp_???.ico」로 지정하고 '확장자'에 「.vgm;.xgm」이 지정되어 있는 경우에는,  
      「c:\ico\mdp_vgm.ico」「c:\ico\mdp_xgm.ico」  
      가 지정된 것이 됩니다.  
  '실행할 프로그램의 전체 경로(와 옵션)'  
      초기값은 「"C:\MDPlayer\MDPlayerx64.exe" "%1"」이 입력되어 있습니다.  
      MDPlayer를 기본값(특별히 변경하지 않고)으로 설치한 경우에는 이 초기값으로 문제없을 것입니다.  
      그렇지 않은 경우에는 조정해 주세요.  
      참고로 "%1"은 더블클릭한 파일의 전체 경로를 의미합니다.
