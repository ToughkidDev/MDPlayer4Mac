MUB 재생을 MucoMSX 재생기(2026-11-13)와 다시 맞췄습니다. Gradius III(SNES 변환) 곡에서 MucoMSX와 달랐던 SCC 음량
시점과 FM 음정을 고쳤고, PCM이 들어 있지 않은 MUB를 MucoMSX와 같은 규칙으로 엽니다.

## 변경 사항

### 재생

- SCC 파트의 `v`(음량) 명령을 읽는 틱에 바로 음량을 씁니다. 이전에는 다음 음표나 엔벨로프 틱에 썼기 때문에
  타이로 이어진 음 사이에서 음량을 바꾸면 MucoMSX보다 한 틱 늦었습니다. OPNA SSG 파트는 MucoMSX와 같이
  그대로입니다.
- FM 소프트웨어 LFO와 포르타멘토의 한 걸음, FM3 확장(S) 슬롯의 디튠을 더할 때 옥타브 경계를 움직이는 쪽만
  검사합니다(MucoMSX와 같음). 이전에는 매 걸음 양쪽을 검사해서, 디튠으로 옥타브 첫 음 아래에 놓인 음이 LFO의
  첫 상승 걸음에 6~16센트 높아졌습니다.
- PCM이 들어 있지 않은 MUB는 `#pcm` 태그에 적힌 파일을 MUB와 같은 폴더에서 읽습니다. 그 파일도 없으면
  ADPCM-B 레지스터를 쓰지 않고 나머지 채널만 연주합니다. `#pcm` 태그가 없는 MUB에서 `mucompcm.bin`을 찾지
  않습니다. MUC는 그대로입니다(컴파일할 때 PCM을 넣습니다).
- PCM 위치는 있지만 크기가 0인 MUB8(이전 MucoMSX 출력)이 열리지 않던 문제를 수정했습니다.

## 검증

- 시험 곡 가운데 이번 수정으로 시퀀서의 칩 쓰기가 달라지는 곡은 msPb0102 형식 210곡입니다. 이 210곡을 MucoMSX
  재생기와 틱 단위로(곡마다 3,000틱) 비교했습니다. 수정 전에는 SCC 음량(15곡 614틱), 한 틱 안의 SCC 음량 변화
  순서(160곡 6,014틱), FM 음정(2곡 12틱)이 MucoMSX와 달랐고, 지금은 모두 같습니다. 남은 차이는 이전과 같은
  곡 시작의 초기화 값입니다.
- 나머지 MSX 형식 867곡과 MUB8 형식 417곡은 수정 전후의 시퀀서 쓰기가 같습니다. 네이티브 형식
  (msPb0103~0109)의 PSG·SCC·MSX-MUSIC 스트림 재생은 이번에 바뀌지 않았습니다.
- 위 세 재생 규칙을 확인하는 회귀 검사를 추가했습니다. 독립 코어·MSX 재생 회귀 검사를 통과했고, GitHub 배포
  작업에서도 다시 검사합니다.
- 자동 검사이며 전곡 청음이나 원본 게임 전체와의 파형 동일성 검증을 뜻하지 않습니다.
