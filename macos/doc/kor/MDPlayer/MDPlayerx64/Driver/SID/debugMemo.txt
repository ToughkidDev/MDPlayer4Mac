SID 빌드 절차 메모
　msys64 를 사용하여 다음과 같이 빌드한다.

　libsidplayfp를 빌드
autoconf
./configure
make install

　sidplayfp를 빌드
autoconf
./configure
make

일단 빌드가 되면,
그 다음은 분석용 코드를 넣으면서 빌드하고 확인하기를 반복한다.

cd ../..
cd libsidplayfp-2.0.4/
make install
cd ..
cd sidplayfp-2.0.1/
make
cd src
./sidplayfp.exe --resid -ri -f44100 Artillery.sid


------------------------


칩 자체의 에뮬레이션은
  libsidplayfp\builders\resid-builder\reSID\
안의
  sid.cs
부근.

   write()
로 칩에 데이터 쓰기.
   clock()
등 clock으로 시작하는 메서드로 렌더링.
