## 변경 사항

- MUCOMSX raw v2의 PSG, SCC/SCC+ 및 소스 OPNA SSG 레지스터 전송 지원.
- 사용 칩 선언에 따른 에뮬레이터 초기화와 SCC+ 5번 채널 독립 파형 처리.
- SCC 주소 자동 증가, 반복 구간의 선택 상태 및 SSG 클록 변환 보정.
- MSX PSG 에뮬레이터 클록 보정.
- raw 스트림에 MSX 플레이어와 같은 정수 샘플 타이머 적용. 템포 변경·타이머 응답에서 위상을 유지해 누적 재생 시간 오차 개선.
- raw v2 합성 테스트 데이터와 선택적인 로컬 앨범 검증 도구 추가.

일반 MUCOM MUC/MUB의 타이머 경로는 기존 방식을 유지합니다.

## 다운로드

Apple Silicon용 **MDPlayer4Mac-osx-arm64.zip**을 내려받아 압축을 풀고 `MDPlayer4Mac.app`을 실행하세요.
macOS 13 이상에서 사용할 수 있으며 .NET 런타임이 포함되어 있습니다.

## 검증

- 합성 MUB 15개·MUC 15개 재생 및 Z80 레지스터·타이머 비교: **1,278,242개 검사 통과**.
- macOS UI Release 빌드 통과.
- 배포 워크플로에서 회귀 검사를 다시 실행하고, 앱 번들 서명·리소스 검증을 수행합니다.

앱은 기존 릴리스와 동일하게 ad-hoc 서명을 사용합니다. Apple Developer ID 서명 및 notarization은 적용되지 않았습니다.
최초 실행 안내와 지원 형식은 [macos/README.md](https://github.com/ToughkidDev/MDPlayer4Mac/blob/v0.2.1/macos/README.md)를 참고하세요.
