이번 릴리즈는 v0.2.4의 검증된 기능을 포함하며, GitHub 실행기 할당 실패를 피하도록 릴리즈 환경을 `macos-15`로 변경했습니다. v0.2.4 태그는 보존하며 앱 파일은 v0.2.5에서 제공합니다.

## 변경 사항

- MDPlayer4Mac 전용 독립 C# 코어 `MDPlayer.MucoNative`를 추가했습니다. MUC 컴파일과 재생을 앱 내부에서 처리하며, MSX CPU·ROM·COM·매퍼·Python이나 외부 MSX 툴체인을 요구하지 않습니다.
- `msPb0103`–`010A`의 PN1–PN6 음악 객체를 지원합니다. MSX PSG, SCC+ 다섯 채널과 OPLL 멜로디·리듬을 기존 OPNA A–K와 함께 재생할 수 있습니다.
- 두 글자 `?` 확장 명령, 기존 `?`/`@` 별칭, 공유 구절·음색·표 선택, 효과 유지·취소·재시작, 전역 페이드와 SCC 파형 변조를 지원합니다. `?WG`의 정적 파형 업로드·공유 게이트 처리도 포함합니다.
- compact 바이트 스윕의 다음 음표 재시작, 기존 PSG `w`의 공유 노이즈 갱신, 효과 취소 후 쉼표의 제어권 해제를 수정했습니다.
- 혼합 MUC의 인라인 FM 음색 정의를 기존 managed MUCOM 형식으로 처리합니다. 공유 구절 정의가 먼저 나오는 compact SCC 채널이 빠지던 문제도 수정했습니다.
- 긴 음표 분할과 SSG 페이지 종료 시 다른 페이지의 음량을 잘못 끄는 처리를 보완했습니다. 기존 MUC/MUB와 OPNA 문법·재생 경로는 유지합니다.
- About에 `MucoMSX 2026-10-26 / msPb010A` 호환 기준을 표시합니다.

## 검증

- 독립 코어 회귀 검사 **1,450개**, 오디오 엔진 회귀 검사 **1,290,226개**를 통과했습니다. 검사 횟수이며 곡 수가 아닙니다.
- ROM/DSK 변환 MUC **743개**를 모두 컴파일·오디오 재생했습니다. 생성 MUB는 툴체인 결과와 바이트가 같고 MUC/MUB 재생 PCM도 모두 같습니다. **497개 자연 종료, 239개 2루프, 7개 20분 재생**을 구분해 확인했습니다.
- 보조 혼합곡 2개에서 SCC+/PSG/OPLL·OPNA 양쪽 FM 뱅크 동시 재생과 정상 종료를 확인했습니다.
- GitHub Samples/Muc 223개 중 **203개 재생**, **18개 음색 정의 전용**, **2개 입력 전처리 오류**로 구분했습니다.
- 위 결과는 자동 오디오·이벤트 검사입니다. 원본 게임 전체와의 파형 동일성, 전곡 청음이나 GUI 실시간 무지연을 뜻하지 않습니다.

## 알려진 제한

- 일부 곡은 장시간 정상 재생하지만 전체 효과 상태의 반복을 감지하지 못해 루프 카운터가 증가하지 않습니다. 해당 곡의 자동 반복 횟수 종료는 추가 점검 대상입니다.
- `sq1_104.muc`와 `pcmt16d2.muc`의 일부 들여쓴 비연주 행을 채널로 오인하는 입력 전처리 문제가 남아 있습니다. 원래 열 배치로 컴파일한 MUB는 정상 재생됩니다.
- 기존 변환의 Quarth 14 및 TwinBee 16 원곡 재현 제약은 이번 플레이어 업데이트로 해결됐다고 주장하지 않습니다.

## 다운로드

Apple Silicon용 **MDPlayer4Mac-osx-arm64.zip**과 **.zip.sha256**을 제공합니다.
macOS 13 이상, .NET 런타임 포함입니다. 압축을 풀고 `MDPlayer4Mac.app`을 실행하세요.

기존 릴리즈와 같은 ad-hoc 서명이며 Developer ID/notarization은 적용되지 않았습니다.
