[PR #1](https://github.com/ToughkidDev/MDPlayer4Mac/pull/1)의 MucoNative 수정과 압축 행 문법 확장을 적용했습니다.

## 변경 사항

- OPLL 멜로디와 MSXG에서 `?FB0 … ?FBn` 반복을 처리합니다.
- `?XT4` 효과 트랙과 MSXG `?XT64`의 `r`를 쉼표로 처리해, 효과 오류와 의도하지 않은 스네어·탐 타격을 수정했습니다.
- `?ID` 타격 전에 대기 중인 `?IT` 키트, 리듬 음량과 `?IB` 베이스 드럼을 반영합니다.
- 파형 모핑의 스트라이드가 공유 파형 데이터 끝을 넘을 때 첫 파형으로 순환하여 재생을 계속합니다.
- 압축 행에서 `|`, 두 겹 `[ ]n` 반복(여러 줄 포함), `L` 루프 지점을 지원합니다. 끝의 `!`는 `L`로 돌아갑니다. `/`는 지원하는 대체 작성법을 오류 메시지로 안내합니다.
- 압축 OPLL 행에서 `?IRn`과 `?IUn`을 지원합니다. PSG 전용 압축곡은 `?WD`가 없어도 컴파일되며, SCC 파형 누락은 `?WD` 안내 오류를 냅니다.
- 오류 메시지에 두 글자 확장 명령 이름을 표시합니다. 기존 `@`·`?` 표기와 OPNA 문법을 유지합니다.

## 검증

- 독립 코어 회귀 검사 **1,468개** 및 오디오 엔진 회귀 검사 **1,290,226개** 통과. 검사 횟수이며 곡 수가 아닙니다.
- OPLL 반복·쉼표·타격 설정과 새 압축 문법 회귀 검사를 포함합니다. SCC+/PSG/OPLL·OPNA 혼합 오디오와 오류 후 재실행 검사도 통과했습니다.
- GitHub 릴리즈 작업은 같은 소스에서 두 검사군, self-contained 빌드, 앱 서명·압축 검증과 시작 검사를 다시 수행합니다.

## 알려진 제한

- `/` 반복 탈출은 압축 행에서 지원하지 않습니다. `[A B]n-1 A` 형태로 작성하세요.
- 일부 긴 곡의 전체 상태 루프 감지와 `sq1_104.muc`·`pcmt16d2.muc`의 들여쓴 비연주 행 전처리 문제는 추가 점검 대상입니다.
- 원본 게임 전곡의 파형 동일성이나 GUI 실시간 무지연을 뜻하는 검증은 아닙니다. 이번 버전은 MSX용 COM 툴체인과 별개인 macOS 네이티브 코어의 업데이트입니다.

## 다운로드
